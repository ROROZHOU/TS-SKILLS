# 默认模板

- [PPTX 原件](../周边场地分析模板.pptx)、[模板哈希](manifest.json)及[逐页计划](page-plan.json)。
- [已编译配置](../webapp/site.config.json)供新项目填写坐标与页配置。样式缺项见 `ppt.style_compilation`。
