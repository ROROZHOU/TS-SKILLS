# 模板筛查与页面计划

## 用户上传模板的适用性检查

先数实际页数（含隐藏页）。超过 20 页即停止，告知页数及上限，请用户精简重传。通过页数检查后，结合文字、图像和套稿语境逐页判断相关性。区位、交通、配套、水绿、规划、实景、红线和相应封面、目录及总结均可相关。其他项目的同类分析可以作为模板。存疑页查看渲染后再判定。

无关页占比超过 50% 时，报告无关页码和占比，请用户精简重传。恰好 20 页或 50% 通过该项检查。写入 `template-screening.json`，记录模板 SHA-256、`source=user_upload`、总页数、逐页判断及理由、无关页和占比、通过状态及停止原因。页数超限时相关性字段可空。未通过初筛即暂停详细提取、检索和制作，等待重传并重新筛查。随包默认模板使用已有页面计划。

## 逐页提取

查看对象树及渲染图。保存含模板 SHA-256 的 `page-plan.json`，每页记录 `page`、`type`、`existing_layers`、`extra_resources` 和 `style_bindings`。分析页补充 `title`、`layout` 和供人工或 AI 逐页复核的 `required_elements`，保留页设置 `action=preserve`。视口及裁切写入项目配置，交付缺项写入页面内容与验收回执。版式记录文字、底图、分析图、图例和图片的位置及层叠关系。

- **纯模板、非场地分析**。标记 `action=preserve`，保留原页序、隐藏状态、全部对象、备注、动画、关系及共享依赖。非场地分析页另记初筛理由。两类页均跳过内容替换和地图采集。
- **卫星底图**。把模板语义映射到地图图层键，记录对象 ID、语义、几何类型、来源及样式引用，核对取数、显示与导出。缺能力标 `unsupported`，经验证的近距用地红线用 `parcelOutlineStyle`。
- **红线底图**。从当前图纸解析用地边界、控制线、退界、标高和指标，记录实体 ID、单位、坐标系、置信度、出处和样式引用。图纸缺项直接记录。

| 模板信息 | 地图图层键 |
| --- | --- |
| 行政区、高速、道路 | `district`、`express`、`road` |
| 水体、河道、绿地 | `water`、`green` |
| 机场、铁路、公交、地铁点位 | `air`、`rail`、`bus`、`metro` |
| 商业、公共服务、体育、公园 | `shop`、`gov`、`sport`、`park` |
| 基地、距离圈、视点 | `project`、`ring`、`view` |
| 地名、水名 | `cityName`、`waterName` 或图层 `label` |

按[样式绑定](template-to-config.md)分别取填色和透明度、线宽和线型、字体与文字样式。点位层与线路层须各自追溯。默认模板的页码和验收项见[默认页面计划](../assets/default-template-extraction/page-plan.json)。

## 额外资源

为专题规划、历史影像或实景照片等额外资料建立 `resource_id`，按页列出用途、已有资料及待补项。用户资料直接核验。待检索项请用户选择全部、指定项或暂不检索，并说明耗时、token 消耗和找不到资料的可能性。同范围已有授权可直接检索，新增或扩大范围时再确认。等待时继续独立工作。

在页面计划记录检索选择、范围、依据与核验状态。区分暂不检索、检索未找到和找到但不适用。优先原始发布机构，保留查询词、出处、日期、覆盖范围及资料状态。专题数据按[规划配准](planning-overlay.md)处理，几何取自当前资料，样式来自当前模板。真实照片保留原图，框线、编号、说明用可编辑对象。
