# 组版验收

交付 PPTX、逐页预览及运行资料，包括输入、模板证据、页面计划、配置、卫星底图 JPG、几何快照 JSON 和来源。

- **页序与依赖**。核对上传模板筛查记录与哈希。纯模板、非场地分析页及指定修订以外的页面，比较 XML、关系、备注及媒体、版式和主题。核对隐藏状态，修订新增媒体使用独立部件。
- **来源与可编辑性**。底图与真实照片用位图。分析页文字、图例、路径及尺寸用原生对象，布局和面线文字样式可追溯到模板。卫星页地理要素来自地图几何快照（JSON），直接用图纸仅限已配准的近距用地红线。红线页引用当前项目图纸。
- **图层和视野**。由人工或 AI 对照逐页预览，按页面计划的 `required_elements` 检查图例和可见对象。该字段供审阅使用；C# 的 `validate` 按 profile、采集回执和 PPTX 对象执行独立检查。截图与快照同中心、缩放、尺寸及裁切。核对道路分级、名称位置、独立枢纽图标、圈的距离或时间含义，以及水面、河道中心线与河名。估算河宽说明口径。
- **专题与缺项**。核对检索范围、发布日期、图件覆盖、分类、配准、孔洞和来源。仅把真实现场拍摄标为实景，将缺资料、无合适图件与未支持样式记入缺项。
- **渲染与私密配置**。逐页检查裁切、重叠、标签和误识别。宿主负责 DPAPI 凭据保管，检查项目目录和交付包中没有明文凭据。

默认组版及通用验收命令见 [地图采集流程](map-capture.md)。自动报告分别记录生成和来源检查、数据完整性。最终可见效果以渲染复核为准。

每个红线底图页按项目清单或页面子集核对所有地块的面、填色与描边；有指标时核对对应地块的文字和位置。
核对 profile.template.preservePages 与逐页计划。封面原样保留时将其列入 preservePages。重建封面且无其他保留页时，cover_dependencies_checked 为 0 属预期，此时另外检查新封面内容与依赖。

整套组版时，模板原页只有经审核列入 `preservePages` 才能原样通过验收。出现“仍为模板原页”时，核对该页的项目文字、图片和图表，并按页面计划重建。逐页预览同时检查页面边界；复制其他画幅的 profile 时，尤其要核对标题、底图、正文和页脚的实际位置。

默认红线页的 `cad` 核对图纸来源和可编辑线稿，`parcels` 核对本页选定地块的闭合面，`legend` 核对图例与图形样式。P9 的 `indicators` 逐地块核对指标值及标注位置；P10 的 `cadTopics` 核对退界依据、已配准的控制线及其类别。资料缺失时，在对应页记录缺项。
