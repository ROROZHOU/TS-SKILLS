# 开发修改版复用记录

对照对象为本次收到的 RAR、与其同目录宿主工程的 TranSketchMcp.SiteContext 源码，以及上一轮 0.2.0 交付快照。RAR 中是技能文档和地图、模板资产，C# 实现位于宿主工程。附件没有指明其分叉提交，以下按功能差异整理。

| 附件中的改动 | 0.3.0 的处理 |
|---|---|
| 启动时登录，编排六个 sitecontext_* 工具，大文件按绝对路径交接 | 复用公司宿主登录和路径约定。模板提取、样式编译、资源导入、组版及验收实现来自同版本宿主源码，并纳入当前插件。新工具使用 plugin_site_* 名称，避免和宿主内置旧实现冲突。 |
| 从模板提取 OOXML、解析主题颜色与对象样式，比较模板 SHA-256 判定能否复用 | 复用提取与溯源逻辑。输出写入本次运行提取目录；出厂技能只保留模板及必要配置。附件和现版默认 PPTX 的 SHA-256 一致。 |
| profile 描述图框、图例、组版页、裁切和验收规则 | 复用结构与默认图框。删除台州站点偏移、路桥区图例、R21/R22/B1、历史图新闻链接、固定审图号、CAD handle 及固定缺项。来源、署名和缺项按本项目页面内容、红线和快照生成。 |
| 旧样式编译器只保留 size/width/core，并从 enabled 重算 on | 修订合并逻辑以保留现有配置字段及显式开关，二次编译结果一致。验收识别道路变体和具有相同模板来源的派生标注。 |
| prepare_run 和 capture 单例监听，手工开浏览器采集，通过 amapConfigPath 读取私有配置 | 保留现版 plugin_capture_site_maps，通过宿主凭据回调和本机匿名管道传值。本版不引入旧版 Key 文件、演示 HTML 和重复展开的媒体。 |
| compose / validate、按页修订与保留页检查 | 使用 C# 生成原生 PPT 对象、验收来源、检查未改页及其依赖。没有项目红线页基准的默认红线页标记待补。 |

**验证范围**：Release 编译及打包；默认模板提取、重复样式编译、含孔洞资源导入、基于历史几何与当前模板样式构造测试输入的七页组版、生成/溯源验收、单页修订与未改页依赖比对。未使用真实客户密钥重新采集卫星影像，未进行新成果逐页视觉签审。浏览器适配器和高德 JS API 继续运行在浏览器内。
